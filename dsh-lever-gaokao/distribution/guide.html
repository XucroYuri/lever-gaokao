立维志愿

高考志愿填报 AI 助手 · 已启动 DeepSeek Harness
1
打开主界面（Harness 已在本机运行）
2
在设置 → Providers 配置 DeepSeek：
Base URL：https://api.deepseek.com
API Key：你在 platform.deepseek.com 申请的 Key
模型：deepseek-v4-flash（便宜，推荐）或 deepseek-v4-pro
3
开始对话，模型会先用「立维问诊」逐层收集考生信息，再查询官方数据给出分析。
打开立维志愿主界面 →
💡 省钱提示：DeepSeek 官方峰谷定价——高峰 9:00-12:00、14:00-18:00（价格翻倍）， 其余闲时半价。候选发现、对抗审查等重任务攒到闲时跑，成本减半。对话中可让模型用 gaokao_offpeak 判断时段并自动调度。
